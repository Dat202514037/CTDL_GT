# Quick Sort
## Mô tả bài toán

* **Input:**
  * Số lượng phần tử trong mảng $n$.
  * Giá trị của từng phần tử trong mảng.
* **Output:**
  * Lần lượt các bước thực hiện sắp xếp qua mỗi lần phân hoạch.
